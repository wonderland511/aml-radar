Что делать по каждому алерту

Скоринг ретроактивен: адрес, чистый сегодня, через месяц может стать грязным за ту же самую транзакцию.

🚨 Новый взлом ≥ порога

Предупреждение, не происшествие. 48–72 часа: не выводить через instant-обменники и свопы без KYC.

⚠️ Обменник ловит грязь

На его горячий кошелёк пришли средства с помеченного адреса. Не выводить через него, пока не отстоится.

🔴 Прямая экспозиция

Худший случай — прямой сап. Средства не двигать, зафиксировать tx, прогнать двумя вендорами.

🟠 Новые адреса в санкциях

OpenSanctions. Средний приоритет — прогнать AML по своим в течение суток.

🔴 Новые адреса в OFAC

Формальное подтверждение того, что аналитики знали давно. Плановая перепроверка.

🟢 Делистинг

Тоже сигнал: статус кошельков, привязанных к снятому адресу, может пересмотреться в плюс.

Установка

Telegram-бот

@BotFather → /newbot → токен. Приватный канал, бот — админ. chat_id через getUpdates.

Ключи API

Etherscan V2 (обязателен, один ключ на 60+ EVM-сетей через chainid). TronGrid — опционально.

Установка и cron

bash install.sh сделает baseline-прогон и предложит прописать расписание автоматически.

git clone https://github.com/wonderland511/aml-radar.git
cd aml-radar
cp config.example.json config.json
chmod 600 config.json
nano config.json
bash install.sh
